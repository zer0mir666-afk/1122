# Atelier Mobile

Мобильный MVP интернет-магазина `by.adigyuzelov` и лаборатория поиска товаров по фотографии.

## Что находится в проекте

- `index.html`, `styles.css`, `app.js` — основной мобильный магазин.
- `serp-lab.html`, `serp-lab.css`, `serp-lab.js` — проверка поиска товаров через SerpApi Google Lens.
- `ai-lab.html`, `ai-lab.css` — предыдущая сравнительная лаборатория моделей.
- `inputs/serpapi-products/` — исходные фотографии товаров для поиска.
- `assets/serpapi-lab/` — ответы SerpApi, скачанные кандидаты и финальная AI-проверка.
- `run_serpapi_batch.py` — загрузка исходников и поиск через Google Lens.
- `run_serpapi_review.py` — визуальная проверка кандидатов через Gemini и GPT.
- `docs/PROJECT_CONTEXT.md` — полный контекст проекта и требований.
- `docs/CHAT_HISTORY.md` — история решений, собранная по всей переписке.
- `docs/RUNBOOK.md` — команды запуска и повторного поиска.
- `docs/CATALOG_CATEGORIES.md` — утверждённые категории и правила классификации.
- `catalog-categories.json` — машиночитаемый список утверждённых категорий.
- `AI_HANDOFF_FULL.md` — единый полный файл для передачи проекта другому ИИ.

## Быстрый запуск

Из папки проекта:

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory .
```

Основной магазин:

```text
http://127.0.0.1:4173/
```

Текущая страница проверки SerpApi:

```text
http://127.0.0.1:4173/serp-lab.html
```

## Переменные окружения

Скопировать `.env.example` в `.env` и заполнить локально:

```env
SERPAPI_KEY=
STARIMG_KEY=
```

Ключи нельзя добавлять в документацию, публичные репозитории или клиентский JavaScript.

## Текущий статус

- Мобильный каталог, листинги, карточки товаров, корзина, оформление заказа и раздел сервиса работают как frontend-демо.
- Четыре реальных исходника прогнаны через SerpApi.
- Для двух Loro Piana выполнен второй поиск с одновременной передачей фотографии и текстового запроса.
- Telegram-бот, база данных, серверный каталог и автоматическая публикация пока не реализованы.

Подробности находятся в папке `docs`.
