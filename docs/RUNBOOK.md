# Рабочая инструкция

## 1. Запуск localhost

Открыть PowerShell в папке `atelier-mobile`:

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory .
```

Проверить:

```text
http://127.0.0.1:4173/
http://127.0.0.1:4173/serp-lab.html
```

## 2. Подготовка ключей

Создать `.env` рядом с `README.md`:

```env
SERPAPI_KEY=...
STARIMG_KEY=...
```

Не вставлять ключи в HTML и JavaScript.

Текущий `run_serpapi_review.py` также умеет читать `STARIMG_KEY` из старого внешнего `.env`, использовавшегося в предыдущем проекте. Для переносимости это следует заменить единым локальным загрузчиком конфигурации.

## 3. Входные изображения

Папка:

```text
inputs/serpapi-products/
```

Текущие имена:

```text
01-brunello-zip-cardigan.jpg
02-brunello-shawl-cardigan.jpg
03-loro-piana-hoodie.jpg
04-loro-piana-jacket.jpg
```

## 4. Запуск поиска для всех товаров

```powershell
python run_serpapi_batch.py
```

Результаты:

```text
assets/serpapi-lab/<product-id>.json
```

## 5. Запуск поиска для выбранных товаров

```powershell
python run_serpapi_batch.py --only 03-loro-piana-hoodie 04-loro-piana-jacket
```

Текстовые запросы сейчас задаются в `QUERY_BY_STEM` внутри `run_serpapi_batch.py`.

## 6. AI-проверка всех товаров

```powershell
python run_serpapi_review.py
```

Скрипт:

1. скачивает выбранных кандидатов;
2. отправляет исходник и кандидатов в Gemini 3.8 Flash;
3. передаёт предварительный вывод в GPT 6.1 Sol;
4. сохраняет итог.

Итоговый файл:

```text
assets/serpapi-lab/review.json
```

## 7. AI-проверка выбранных товаров

```powershell
python run_serpapi_review.py 03-loro-piana-hoodie 04-loro-piana-jacket
```

Существующие остальные блоки сохраняются.

## 8. Обновление страницы

`serp-lab.js` загружает `review.json` при открытии страницы. После нового анализа достаточно обновить браузер.

## 9. Значение файлов

- `run_serpapi_lens.py` — старый одиночный тест.
- `run_serpapi_batch.py` — актуальный пакетный поиск.
- `run_serpapi_review.py` — актуальная визуальная проверка.
- `run_multi_model_hunt.py` — старый эксперимент, в котором модели пытались искать сами.
- `run_ai_lab_*.py` — предыдущие сравнительные эксперименты.
- `assets/ai-lab/` — старые тестовые результаты; не являются текущей производственной схемой.

## 10. Известные ограничения текущего теста

- SerpApi может не найти модель, если исходная фотография нигде не индексируется.
- Подпись с брендом улучшает выдачу, но может создать ложное смещение.
- Текущая AI-проверка использует ограниченный набор кандидатов.
- Текст страницы товара ещё не извлекается Crawl4AI.
- Материал нельзя считать подтверждённым только по внешнему виду.
- Уверенность модели и процент визуального совпадения пока не разделены.

## 11. Рекомендуемая следующая техническая работа

1. Вынести товары и запросы в отдельный manifest JSON.
2. Добавить чистый поиск и поиск с `q` для каждого товара.
3. Объединить и дедуплицировать кандидатов.
4. Добавить локальный FashionSigLIP.
5. Отправлять в Gemini только лучшие 8–10 кандидатов.
6. Использовать GPT как финального проверяющего.
7. Вызывать Claude только при разногласии.
8. Извлекать данные выбранной страницы.
9. Добавить Telegram approval workflow.
10. Подключить backend каталога.

## 12. Проверки перед передачей

```powershell
python -m py_compile run_serpapi_batch.py run_serpapi_review.py
node --check serp-lab.js
```

Также проверить, что все пути из `review.json` существуют и localhost отвечает кодом `200`.
