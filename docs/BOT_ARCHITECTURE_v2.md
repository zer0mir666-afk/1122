# Архитектура Telegram-бота by.adigyuzelov — v2

Дата: 7 ноября 2026 года.

---

## 1. Главная идея

Владелец отправляет боту фото товаров (одно или несколько) с подписью или без.
Бот берёт каждый товар по одному фото, ищет его в интернете, скачивает ВСЕ найденные фото,
создаёт описание, определяет категорию, цвет, размеры — и отправляет готовый пост
на согласование владельцу с кнопками.

## 2. Полный flow

```
Владелец отправляет в бот:
  ─ 1 фото = 1 товар
  ─ 3 фото = 3 товара (каждое фото — отдельный товар)
  ─ подпись (если есть): "Куртка Loro Piana, 100% шерсть, M-3XL"
        │
        ▼
┌─ Шаг 1: Приём и разбор ─────────────────────┐
│                                               │
│  Бот скачивает ВСЕ фото из сообщения         │
│  Каждое фото = отдельный товар               │
│  Если есть подпись → парсим:                  │
│    бренд, тип, материал, размеры              │
│  Если подпись общая на все фото →             │
│    применяем ко всем товарам                  │
│                                               │
│  Бот отвечает:                                │
│  "📸 Получено 3 фото. Начинаю поиск..."       │
└───────────────────┬─────────────────────────┘
                    │
                    ▼ (для каждого товара параллельно)
┌─ Шаг 2: Поиск товара ───────────────────────┐
│                                               │
│  SerpAPI Google Lens:                         │
│  ─ Загружаем фото через SerpAPI Image API    │
│  ─ Поиск по фото (всегда)                    │
│  ─ Поиск по фото + текст (если есть бренд)   │
│  ─ Объединяем, убираем дубли                 │
│  ─ Получаем ~20-50 кандидатов                │
└───────────────────┬─────────────────────────┘
                    │
                    ▼
┌─ Шаг 3: Скачивание ВСЕХ фото товара ────────┐
│                                               │
│  Из лучших кандидатов:                        │

│    (AI визуальное сравнение через Gemini)     │
│  ─ Переходим на страницу лучшего совпадения  │
│  ─ Скачиваем ВСЕ фото товара со страницы     │
│    (Crawl4AI или прямой парсинг)              │
│  ─ Обычно 3-8 фото: фронт, спина, детали    │
│  ─ Сохраняем в assets/products/{id}/         │
│                                               │
│  Если точный товар не найден:                 │
│  ─ Берём лучшие фото из кандидатов           │
│  ─ Помечаем: "похожие модели, не точное"     │
└───────────────────┬─────────────────────────┘
                    │
                    ▼
┌─ Шаг 4: Создание карточки ──────────────────┐
│                                               │
│  AI (GPT) генерирует:                         │
│                                               │

│     Пример: "Loro Piana — Куртка из шерсти"   │
│                                               │

## 3. Кнопки — подробное описание

### 🟢 Добавить (зелёная)

Товар публикуется в магазине как есть.

```
Владелец нажал "🟢 Добавить"
  → product.status = 'approved'
  → Категория становится видимой (если была пустой)
  → Бот: "✅ Товар добавлен в магазин!
           📂 Категория: Куртки
           Всего товаров в магазине: 47"
  → Кнопки исчезают, текст обновляется:
     "✅ ДОБАВЛЕНО — 07.11.2026 15:30"
```

### 🔴 Не добавлять (красная)

Товар отклоняется.

```
Владелец нажал "🔴 Не добавлять"
  → product.status = 'rejected'
  → Бот: "❌ Товар не добавлен"
  → Кнопки исчезают, текст обновляется:
     "❌ ОТКЛОНЕНО — 07.11.2026 15:30"
  → Данные сохраняются в базе для аналитики
```

### 🟡 Изменить описание (жёлтая)

Владелец хочет изменить описание или название.

```
Владелец нажал "🟡 Изменить описание"
  → Бот: "✏️ Напишите новое описание или что исправить.
           Можно написать свободным текстом:
           'Убери про молнию, добавь что есть капюшон'"
  → Владелец пишет текст
  → AI переписывает описание с учётом правок
  → Бот отправляет обновлённый пост
  → Снова кнопки под постом
```

### 🔵 Изменить цену (синяя)

Цена не определяется автоматически — владелец устанавливает сам.

```
Владелец нажал "🔵 Изменить цену"
  → Бот: "💰 Введите цену товара (только число):
           Пример: 185000"
  → Владелец: "185000"
  → product.price = "185 000 ₽"
  → Бот: "💰 Цена установлена: 185 000 ₽"
  → Обновлённый пост с ценой

Примечание: цена НЕ берётся из интернета.
Владелец сам решает, за сколько продавать.
Если цена не установлена → в магазине кнопка "Узнать цену".
```

### ⚪ Изменить размеры (белая/серая)

Если стандартный размерный ряд не подходит.

```
Владелец нажал "⚪ Изменить размеры"
  → Бот: "📐 Текущие размеры: S, M, L, XL, 2XL
           Напишите нужные размеры через запятую:
           Пример: M, L, XL, 2XL, 3XL"
  → Владелец: "M, L, XL, 2XL, 3XL"
  → product.sizes = ["M", "L", "XL", "2XL", "3XL"]
  → Обновлённый пост

Или быстрые кнопки:
  [Одежда S-2XL]  [Одежда M-3XL]
  [Обувь 38-45]   [Свои размеры]
```

### 🟣 Повторить поиск (фиолетовая)

Если найденные фото не подходят или поиск не сработал.

```
Владелец нажал "🟣 Повторить поиск"
  → Бот: "🔍 Хотите уточнить поиск?
           Напишите бренд, модель или любые
           подсказки для поиска.
           Или нажмите 'Искать как есть'."
  → Владелец: "Это Brunello Cucinelli кардиган"
  → Новый поиск с текстовой подсказкой
  → Новый пост с результатами
```

### 🔗 Открыть источник (ссылка)

URL-кнопка (открывает в браузере, не callback).

```
Открывает страницу товара на сайте-источнике.
Например: mrporter.com/loro-piana-jacket
Если источник не найден → кнопка не показывается.
```

## 7. Обработка нескольких фото в одном сообщении

```
Владелец отправил 5 фото с подписью:
"Loro Piana. Куртка, свитер, брюки, ремень, кроссовки.
 Всё M-3XL, кроссовки 40-45."

  → Бот: "📸 Получено 5 фото. Обрабатываю каждый товар..."

  → 5 параллельных задач:
     Товар 1/5: фото 1 + "Loro Piana куртка"
     Товар 2/5: фото 2 + "Loro Piana свитер"
     Товар 3/5: фото 3 + "Loro Piana брюки"
     Товар 4/5: фото 4 + "Loro Piana ремень"
     Товар 5/5: фото 5 + "Loro Piana кроссовки"

  → Каждый товар → отдельный пост на согласование
  → Все 5 постов отправляются последовательно
  → Под каждым свои кнопки
```

Если подпись не содержит деталей для каждого фото:

```
Владелец отправил 3 фото с подписью:
"Brunello Cucinelli"

  → Все 3 товара получают бренд "Brunello Cucinelli"
  → Тип товара AI определяет по фото
```

Если подписи нет вообще:

```
Владелец отправил 2 фото без подписи

  → Бот ищет только по фото
  → AI определяет бренд, тип, цвет по изображению
  → Всё остальное — стандартное
```

## 11. Что происходит после "Добавить"

```
1. product.status = 'approved'
2. product.approved_at = сейчас
3. Если категория "Куртки" была пустой:
   → categories["jackets"].has_products = True
   → Категория появляется в магазине
4. Фото из assets/products/{id}/ доступны через API
5. Frontend загружает товар через GET /api/products
6. Товар виден на сайте

Бот отвечает:
"✅ Товар добавлен!
